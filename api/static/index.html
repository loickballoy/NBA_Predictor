Le modèle

Erreurs mesurées sur le jeu de test (saisons jamais vues pendant l'entraînement), comparées à une baseline simple : « le joueur refait exactement sa dernière saison ».

Comment ça marche

Le pipeline complet tourne sur Google Cloud et se réentraîne chaque semaine pendant la saison. Cette page en est un instantané statique.

  1. Collecte

    Stats de carrière et récompenses de tous les joueurs via nba_api, stockées en Parquet dans un bucket.

  2. Dataset

    Fenêtres de 3 saisons consécutives → la saison suivante. Découpage temporel train / validation / test, sans fuite.

  3. Entraînement

    Perceptron multicouche écrit en C++ sans librairie. Promu seulement s'il bat la baseline et le modèle en production.

  4. Service

    API FastAPI sur Cloud Run. Claude rédige l'explication ; une réponse qui invente un chiffre est rejetée.
